# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- Repository foundation: prototype reference, wp-env and Docker Compose environments, tooling, CI and deploy workflows.
- Content model in Techvenza Core: article meta (reading time, format, guide level, key points, featured/trending/editor's-pick flags, assigned editor, disclosures, corrections, SEO), category term meta (colours, icon, intro, "what to watch", hero image, SEO, homepage flag, order) with contrast check, Series taxonomy, author/reader user meta with profile photo, private CPTs (applications, campaigns, contact messages, redirects), custom tables (subscribers, post views, reading history, notifications) with versioned migrations, encrypted settings store and block-editor document sidebar.
- Blocks: 54 dynamic blocks (header, navigation with mega-menu, search overlay with live suggestions, footer, homepage sections, listing pages, category/author/article/search/404 templates, document layout) with sidebar controls, server rendering and crawlable filter URLs enhanced in place through a fragment REST endpoint; REST routes for session, search suggestions, reader bookmarks/topics/history and view beacons; article reading tools (progress, table of contents, text size, dark reading theme).
- Editorial workflow: custom statuses, server-side transition engine with checklist, notes, scheduling and timeline; roles (applicant, author, editor, managing editor) with capability locks and suspension; in-app notifications and template emails on every transition; REST endpoints for workflow state/transitions and notifications.
- `wp techvenza seed|reset|migrate|aggregate`: imports the prototype's categories, authors, 26 articles, 11 workflow items, applications, subscribers, campaigns, redirects, notifications, pages and menus (images sideloaded from Unsplash unless `--skip-images`); demo passwords are printed once.
- Accounts: branded login, registration with email verification, forgot/reset password on the core key flow (branded emails), password change and email change with confirmation, GDPR deletion requests, login throttling, honeypot, Cloudflare Turnstile / reCAPTCHA v3, optional Google sign-in, wp-login.php redirects and wp-admin lockdown for readers.
- Reader dashboard (overview, saved, history, preferences & profile) and author portal (dashboard, my articles, submission details with feedback and timeline, author profile with photo upload, analytics from first-party view counts, notifications, account settings) in a shared app shell; writing happens in the block editor.
- Editorial admin (wp-admin → Editorial): dashboard with pipeline stats and charts, review queue with bulk actions and a detail view (preview, checklist, feedback, timeline, note-required transitions), drag-to-reschedule editorial calendar with an accessible agenda, author applications with approve/decline and account provisioning, authors screen (visibility, featured and staff flags, suspend/reactivate), analytics with period comparison and CSV export, editable roles & permissions matrix, and workflow/editor/views columns on the posts list.
- Newsletter: double opt-in sign-ups (newsletter page with topics, frequency and consent; compact forms), scanner-safe and RFC 8058 one-click unsubscribe, Brevo and Mailchimp sync of confirmed contacts, campaigns composed from published articles with preview, test send, scheduling and background delivery; admin subscriber list with filters, CSV export, unsubscribe and erasure.
- Forms: contact form routed by inquiry type with acknowledgement emails and an admin inbox (handled/open, retention clean-up), and the author application form with references, duplicate protection and editor notifications; both work with and without JavaScript.
- Scheduled jobs: hourly view aggregation, daily removal of unconfirmed sign-ups and expired contact messages.
- SEO: document titles with custom SEO titles, meta descriptions, canonical URLs (custom canonical per article), robots rules (noindex for search, account pages, flagged posts and optional tag/author archives), Open Graph and X cards, JSON-LD (Organization, WebSite with SearchAction, NewsArticle, ProfilePage/Person, BreadcrumbList), Search Console verification and core sitemap tuning.
- Privacy: consent banner with “Essential only” / “Allow all”, footer “Cookie preferences” re-opener, analytics (GA4 or Plausible) loaded only after consent, optional browser storage gated by consent.
- Settings screen (Editorial → Settings): every option in tabs with constant locks, write-only encrypted secrets, editable email templates and connection tests for SMTP, Brevo, Mailchimp, Turnstile, reCAPTCHA and Google sign-in; the review checklist and favicon/site icon are driven from settings.
- Documentation: admin guide, content model (meta, taxonomies, roles, post types, tables, REST routes, WP-CLI), deployment guide with configuration constants, CI/CD, rollback and the launch checklist of information and keys needed.
- Answer engines (AEO/GEO/AIO): per-article answer-first summary, FAQ (FAQPage JSON-LD), cited sources and focus keyword in a new "Search & AI answers" editor panel with live SEO/answer-readiness checks; richer schema (abstract, about, citation, speakable, editor, isPartOf, WebPage/AboutPage/ContactPage, CollectionPage with ItemList); `/llms.txt`, `/llms-full.txt` and a clean Markdown version of every article and page at `…/md/`; robots.txt groups for AI search and AI training crawlers (each switchable); IndexNow pings on publish; RSS image enclosures.
- Partners & backlinks: a Partners list (Editorial → Partners) with link type (follow, nofollow, sponsored, UGC), keywords that are auto-linked on first mention, an end date and a Partners block; a site-wide outbound-link policy (new tab, default rel, sponsored articles force rel="sponsored").
- Images: an original SVG illustration library (three variants for each of the 17 topics plus page illustrations) imported into the Media Library; articles without a photo fall back to their category image, the default cover or the topic illustration — all replaceable in the Media Library; JPEG social cards for sharing; safe SVG uploads for editors (sanitized).
- Bulk Blog (Editorial → Bulk Blog): import many articles from one CSV (title, content in HTML/Markdown/text, slug, author, category paths, tags, status, publication date, featured image URL or ZIP file, alt text, caption, meta title/description, focus keyword, summary, FAQ, sources and more) with a validation preview, update/skip/duplicate handling, batched import with progress, inline image import, a results report and `wp techvenza import-csv`.
- Tests: PHPUnit suites for the workflow engine, newsletter, forms and settings; Playwright end-to-end suites (public pages, accounts, admin, forms, consent and SEO) with axe accessibility scans; failing PHPUnit tests are reported as CI annotations.
